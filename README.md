# 🎵 Desktop Audio Player

A feature-rich desktop audio player built with **C++** and the **JUCE Framework**, supporting dual-track mixing, real-time waveform visualization, and advanced playback controls.

---

## ✨ Features

- 🎛️ **Dual-Player Mixer** — Play two tracks simultaneously with independent volume control and crossfading
- 📊 **Real-Time Waveform Visualization** — Live waveform rendering with smooth playback tracking
- ⏩ **Variable Speed Playback** — Adjust speed from 0.5x to 2.0x
- 🔁 **A-B Looping** — Loop any section of a track
- ⌨️ **Keyboard Shortcuts** — Full keyboard accessibility for all controls

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| C++ | Core application logic |
| JUCE Framework | Audio engine & GUI components |

## 🧠 OOP Concepts Applied

- **Encapsulation** — State management for playback engine
- **Inheritance** — Custom JUCE components
- **Polymorphism** — Flexible GUI-audio interaction

## 🚀 Getting Started

### Prerequisites
- C++ compiler (GCC / Clang / MSVC)
- [JUCE Framework](https://juce.com/get-juce/)
- Projucer (comes with JUCE)
